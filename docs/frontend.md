# Frontend

**Vorhanden:** Vite/React/TypeScript-Platzhalter (`App.tsx` zeigt nur den Projektstatus). **Geplant:** alles Weitere. **Offen:** Quellendarstellung, UI-Bibliotheken-Details.

Geplant: Chat-Verlauf, Eingabe, Senden, Streaming, Markdown, Syntax-Highlighting, Copy-Button für Code, Quellenanzeige, Lade-/Fehlerzustände, Modellanzeige, verwendete Dokumente, optionale Filter. Tailwind CSS und shadcn/ui sind geplant.

Kommunikation ausschließlich über die definierten API-Endpunkte (`GET /api/health`, `POST /api/chat`, `POST /api/ingest`, `GET /api/documents`, `GET /api/models`).
